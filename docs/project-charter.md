# Project charter

## Purpose

Demonstrate a compact Python REST API with FastAPI, asynchronous MongoDB access through Motor, Pydantic request models, and a simple MVC-inspired separation.

## Portfolio value

Retain this repository as a Python/FastAPI/MongoDB breadth example. Its value is educational architecture and CRUD flow, not a claim of production-grade identity, configuration, or operations design.

## Current scope

- REST operations for a user-shaped resource.
- FastAPI routing, CORS configuration, status codes, and automatic API documentation.
- Controller/model separation around Motor and MongoDB.
- Docker and Docker Compose assets for a local API/database topology.

## Outside the current scope

- Authentication, authorization, secure credential storage, or account lifecycle design.
- Configuration consistency, secrets management, CI, observability, or production deployment.
- Automated test suite implementation and dependency modernization.
